진행 중인 공고와의 충족 여부

DB에 저장된 공고에 대해 한국 정부지원사업의 기본 요구 서류 프리셋(사업체 유형별)을 적용해 매칭합니다. 실제 요구 서류는 첨부 공고문에 적혀 있으므로 최종 확인은 본인 책임입니다.

공고 PDF 분석 (베타)

공고문 PDF를 업로드하면 신청 자격 조건과 유의사항을 자동으로 추출합니다. 업로드한 PDF는 본인의 로컬 서버(planner/storage/)에만 저장되며, 분석 결과는 같은 파일을 다시 올리면 캐시에서 즉시 응답합니다. Vercel 배포본에서는 파일시스템 쓰기가 막혀 동작하지 않으니 본인 PC에서 python -m planner.web 으로 띄워 사용하세요.

업로드한 파일은 현재 선택된 폴더에 들어갑니다. 다른 공고를 분석하려면 새 폴더를 만들고 전환하세요.
